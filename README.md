## How to Run

1. Open the AFTER_DARK folder in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. Your website will open in the browser.

## Current Features

- Dark Romance visual theme
- 25 personalised experiences
- Experience detail popups
- Redeem buttons
- Local browser redemption tracking
- Remaining coupon counter

## Important Notes

The current redemption system uses browser localStorage. It does not synchronise between devices or browsers.

The access-code configuration is not secure authentication. Do not publish the project as a genuinely private website until proper authentication and database-backed redemption tracking are implemented.
